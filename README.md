# シンプル連続再生 v1.4.2

Amazon Prime VideoのOP・EDを楽しみながら、同一シーズンの次のエピソードへ進むChrome／Firefox用拡張機能です。

2026年9月中旬頃から見られるPrime Videoの連続再生の動作変更に対応しました。

## ダウンロード

[リリースページ](https://github.com/KinaPPP/simple-continuous-play/releases/latest)から、お使いのブラウザー用ファイルをダウンロードしてください。

| ブラウザー | v1.4.2の配布ファイル |
| --- | --- |
| Chrome | `simple-continuous-play-v1_4_2.zip` |
| Firefox 128以降 | `simple-continuous-play-v1_4_2.xpi`（Mozilla署名済み） |

GitHubが自動生成する「Source code」は開発用ソースです。通常のインストールには上記の配布ファイルを使用してください。

## インストール

### Chrome

1. Chrome用ZIPを専用のフォルダーへ展開します。
2. `chrome://extensions` を開き、「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」を選び、展開した **`manifest.json`が入っているフォルダー** を指定します。
4. Prime Videoページを再読み込みします。

ZIPの直下に拡張機能のファイルが入っています。展開先のフォルダーは、使用中は削除・移動しないでください。
更新時は同じフォルダーのファイルを差し替え、拡張機能の再読み込みボタンを押してからPrime Videoページも再読み込みしてください。

### Firefox

1. Firefoxの「アドオンとテーマ」を開きます。
2. 歯車メニューの「ファイルからアドオンをインストール」を選び、ダウンロードしたXPIを指定します。
3. 表示される確認画面に従ってインストールします。
4. Prime Videoページを再読み込みします。

配布XPIは署名済みなので、一時的なアドオンとして読み込む必要はありません。
テスト用の一時読み込み版が残っている場合は、先に削除してください。

## 使い方

1. Prime Video側の「自動再生」をONにします。
2. 拡張機能のポップアップで「連続再生を有効にする」をONにします。
3. 動画を再生します。全画面で視聴したい場合は、プレイヤーを全画面にしてください。

通常の設定はON／OFFだけです。ON／OFFを変更した後は、Prime Videoページを再読み込みすると完全に反映されます。

## 主な動作と注意点

- OP／EDのスキップボタンを自動で押しません。
- 早いタイミングのNext Up表示を遅らせ、終了間際の確認済み次話カードを残します。
- 次話の話数・画像を一覧と照合し、別作品を次話として自動再生しないようにします。
- 公式プレイヤー内で次話へ移行できた場合は、全画面表示を維持できます。
- 動画の終了を確認した後、必要に応じて一覧の確認済み次話URLで再生を補助します。この場合、全画面表示が解除されることがあります。
- おすすめパネルに対する自動再生の停止・非表示処理も含みます。

**一部の作品や再生環境では、次話へ進まない場合があります。** 終了通知が届かない場合などには、誤った再生を避けるため次話を強制再生しません。Chrome・Firefoxとも、すべての作品・環境での動作を保証するものではありません。

公式の次話移行タイミングはAmazon側の処理にも依存するため、動画の最後の全フレームまで再生されることは保証しません。Amazon側の変更や、他の再生関連拡張機能の影響で動作が変わる場合もあります。

問題が起きた場合は、拡張機能をOFFにしてPrime Videoページを再読み込みしてください。

## 不具合の報告・診断ログ

1. 問題が発生したPrime Videoタブで、拡張機能のポップアップを開きます。
2. 「困ったとき・診断ログ」を開き、「診断ログを取得」を押します。
3. 「JSONで出力」で保存するか、「ログをコピー」で取得します。
4. [Issues](https://github.com/KinaPPP/simple-continuous-play/issues)で、ログと次の情報をお知らせください。

- 作品名・シーズン・何話から何話への移行か
- 使用ブラウザーとバージョン
- 発生した状況（一覧に戻る、全画面が解除される、次話が始まらない等）
- 広告の有無、他の再生関連拡張機能の使用状況

作品名や話数などは報告文に記入してください。ログは保存件数に上限があるため、できるだけ問題が起きた直後に取得してください。

診断ログには、拡張機能のバージョン、話数、再生位置、操作日時、画面サイズ、全画面状態、ボタンの検出結果などを記録します。作品名・URL・パスワード・Cookieなどの認証情報を記録する設計にはしていません。ログの自動送信は行いません。

日時や再生状況は含まれます。公開する前に内容を確認し、報告文にもアカウント情報や秘密鍵を記載しないでください。

## 開発・ビルド

Chrome用とFirefox用は、共通ソースから生成します。Python 3で、リポジトリのルートから実行してください。

```sh
python build.py
```

- `dist/chrome/`：Chromeで読み込むフォルダー。
- `dist/firefox/`：Firefoxの署名・一時テスト用フォルダー。
- `dist/*-candidate.zip`：ブラウザー別の生成ZIP。Firefox用ZIPは未署名です。

開発中のFirefox版は、`about:debugging#/runtime/this-firefox`から`dist/firefox/manifest.json`を一時的に読み込めます。リリースページの署名済みXPIとは別の用途です。

Node.jsで模擬テストを実行できます。

```sh
node --test tests/*.test.cjs
```

模擬テストに加え、実機で連続数話・最終話／映画・ON/OFF・一覧経由の再生を確認してください。

### Firefoxの署名（開発者向け）

Node.js／npmとMozillaの署名用API認証情報が必要です。

1. `python build.py`で最新の`dist/firefox/`を生成します。
2. `sign-firefox.local.bat.template`を`sign-firefox.local.bat`へコピーし、自分の認証情報を設定します。
3. `sign-firefox.local.bat`を実行します。
4. 対象とバージョンを確認して署名を開始します。

署名バッチは`dist/firefox/`を対象にし、成果物を`web-ext-artifacts/`へ出力します。自己配布用の`unlisted`申請です。

**認証情報を記入した`sign-firefox.local.bat`は公開しないでください。** `dist/`、`web-ext-artifacts/`、ローカル署名設定などは`.gitignore`で除外しています。GitHubのWeb画面へ手動アップロードする場合は、これらを選択しないようにしてください。

- Prime Videoの動作変更に対応し、表示遅延と次話の照合・引き継ぎを改善。

- 診断ログの取得・コピー・JSON出力を追加。
